# Raachi Memory

> **Never forget what matters.**

Raachi Memory is an offline-first Android application built with **Kotlin**, **Jetpack Compose**, and **Material 3**.

## Version

v1.0.1

## Status

Release candidate. Core offline functionality is complete; Play Store release preparation remains.

## Features

- Smart reminders with exact alarms, custom sound, snooze, and completion actions
- Money and item Ledger with due alerts, contact picker, and WhatsApp sharing
- Daily Expense Manager with bank, cash, and wallet accounts
- Debit, credit, transfer, filtering, and balance tracking
- Local profile, activity history, light/dark themes, and branded UI
- Versioned JSON backup and restore
- Reboot and timezone alarm reconciliation
- Offline-first storage with no mandatory login or cloud dependency

## Technology Stack

- Kotlin
- Jetpack Compose
- Material 3
- Room
- Hilt
- Navigation Compose
- AlarmManager
- WorkManager
- DataStore
