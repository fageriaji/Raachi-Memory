# UI_GUIDELINES.md

# Raachi Memory v1.0

## Design Philosophy

Calm, clean, modern, card-based and easy to use.

## Design Language

-   Material 3
-   Jetpack Compose
-   Google Poppins
-   Rounded corners
-   Soft shadows
-   Adaptive dark theme

## Typography

App Title: SemiBold Greeting: SemiBold Card Title: Medium Body: Regular
Buttons: Medium

## Colors

Primary: Indigo Success: Emerald Warning: Amber Error: Soft Red Surface:
White Dark: Charcoal

## Layout

Screen padding: 16dp Card radius: 24dp Card padding: 16dp

## Dashboard

Greeting: Good Morning/Afternoon/Evening {Name}

Cards: - Up Next - Pending Ledger - Today's Summary

FAB: Add Reminder Add Ledger

## Navigation

Bottom Navigation: Dashboard Reminders Ledger Activity Profile

Settings from Profile.

## Reminder Cards

Icon, title, time, status. Actions: Done Snooze Skip

## Ledger Cards

Person, amount/item, due date. Actions: WhatsApp Mark Returned

## Animations

200-300ms Fade Scale Material Motion

## Accessibility

48dp touch targets. Dark mode. Readable typography.

## Empty States

Explain what to do next. Example: No reminders yet. Tap + to create one.

## First Launch

Splash → Welcome → Name (Required) → Optional Profile → Dashboard

## UX Rules

One primary action per screen. Avoid clutter. Keep forms short. Use
bottom sheets where suitable.

## Summary

Every screen should reinforce: Never forget what matters.
